# Корица — сайт кофейни

Учебный проект: одностраничный сайт вымышленной кофейни «Корица».

- Главный экран, «О нас», меню с вкладками (кофе / чай / десерты), галерея, отзывы, контакты
- Выбор размера кофе (S / M / L) и корзина: итоговая сумма, изменение количества, удаление товара
- Переключатель языка RU / EN
- Адаптивная вёрстка под телефон
- Чистый HTML, CSS и JavaScript без сборки

**Адрес:** https://shiro-dev1.github.io/project-3/

Фото: [Unsplash](https://unsplash.com). Кофейни не существует, адрес и телефон вымышленные.
